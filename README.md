# GameLingo AI — iPhone Offline Game Translator

Native iOS experimental prototype for **one iPhone**, featuring on-device OCR (Apple Vision), Apple Translation, ReplayKit screen capture, and an experimental PiP subtitle surface. No OpenAI API key, external translation service, or relay server is required.

**Status:** source prototype; not yet Xcode-built or device-tested. Game overlays are subject to iOS, ReplayKit, App Groups and PiP constraints. Sideload signatures may lack App Groups entitlement.

The full Xcode sources and Codemagic build configuration are being uploaded to this private repository. Follow the detailed Chinese instructions in `README.md` once the source expansion commit appears.
