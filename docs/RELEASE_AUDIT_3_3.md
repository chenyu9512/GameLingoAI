# GameLingo Direct 3.3 一次性全局审查记录

日期：2026-10-23（源代码审查，非真机测试）

## 已完成的源码检查与修复

### 隐私、安全、在线翻译
- [x] \`GameLingoStore\` 的默认翻译引擎是 \`.offline\`；对老版本 Saved 结构使用可选 \`provider\` / \`endpoint\` 以兼容升级。
- [x] 网络服务必须明确选择、进行测试并启用；并非启动后自动联网。远程只接收待翻译文字，不接收原始采集图片。
- [x] LibreTranslate / 自定义 REST 请求地址校验 HTTPS，拒绝内嵌用户密码；API key 在 iOS Keychain 存储。
- [x] MyMemory 文本按 UTF-8 字节拆段，每段 <500 字节，每日本地匿名额度上限 4,900 字符。
- [x] 自定义 API 支持文本、源语言、目标语言 JSON 参数名，鉴权头和 JSON 返回字段路径；非通用 GraphQL / OAuth2 / GET 模板适配器。
- [x] 在线错误阻止后续菜单批量请求并保留已有结果，不会自动切换到另一个在线服务。
- [x] 实时翻译缓存区分 provider；菜单缓存进一步区分 provider + endpoint，避免更换服务器后返回旧服务结果。
- [x] 明确标注截图翻译强制离线，即使实时翻译使用在线服务，导入截图也不会把文字发送给第三方。
- [x] **API 可用性证据**：MyMemory 官方 API 文档、额度文档与第三方 2026-10-22 HTTP 200 探测；当前执行环境因网络 DNS 失败未完成独立的实时 HTTP API 探测，已内置用户发起的真联网测试门槛。

### 离线语言与术语
- [x] 无语言模型随包嵌入；下载由 Apple \`TranslationSession.prepareTranslation()\` 在手机上按需触发。
- [x] OCR 源语言改由 \`VNRecognizeTextRequest.supportedRecognitionLanguages()\` 检查兼容 regional code，不再把全部非日语识别回落到日语。
- [x] Vision OCR 的支持语言列表按快速/精确档位缓存，避免每帧重复查询影响识别速度。
- [x] 内置 474 条日语 RPG 词条、分类/搜索、自定义加入；含《勇者斗恶龙》怪物与咒文等短术语及原创通用 NPC/战斗句。
- [x] 优先级为自定义词 > 本地内置术语 > 翻译 API；《勇者斗恶龙》特定术语可按游戏开启，不强加给不相关游戏。
- [x] 术语没有复制《勇者斗恶龙》成段剧情对白；部分专有名词中文音译会因游戏中文版本不同而变化。

### 既有游戏采集与打包
- [x] 竖屏/横屏方向判定、独立 ROI 编辑、手动旋转、截图 EXIF 修复代码仍保留。
- [x] PiP 双语布局（原文在上中文在下）、全屏菜单 OCR 分区、菜单历史、全屏页面记录和截图导入仍保留。
- [x] 新增 Swift 源文件纳入 \`tools/build_xcodeproj.py\` 直采目标和 Codemagic Swift 语法预检列表。
- [x] iOS 27 单 App 直采目标不包含 BroadcastUpload.app-extension / App Groups 签名权限。
- [x] 版本标记：3.3.0 (Build 7)；Codemagic 工作流 \`ios-direct-unsigned\`。

## 已知边界和残余风险

1. iOS 后台调度、PiP 位置及部分游戏防录制限制，均无法从源码层面保证消失。
2. iOS Translation 支持的语言对和 Vision OCR 支持的语言不完全相同；按需下载成功不等于该游戏语种一定 OCR 成功。
3. MyMemory 免费匿名额度并不适合高频、持续整晚的在线游戏翻译，可能触发限流或服务质量下降；默认离线更适合长时间游玩。
4. 静态菜单采用“识别到的全文本块在 App 内查看”，并不支持在第三方游戏上逐处绘制任意数量的中文原位覆盖。
5. 完全一致的词条优先字典不等于一个能理解全部游戏剧情的语义模型；不保证所有句子语境或《勇者斗恶龙》专有名词的各地发行版中文译法统一。
6. 自定义 REST 仅适配 HTTPS POST JSON，部分 API 需要另行适配请求字段、鉴权或响应结构。
7. 因执行环境没有 macOS/Xcode iPhone SDK，也无法直接对 MyMemory 发起实时 GET，不得声称本次已完成编译、联网实测、SideStore 安装、PiP 后台稳定性等验收。

## 真机验收建议

1. 确认默认模式为 **本机翻译**；联网关闭后运行日语游戏仍能离线翻译已下载的语言。
2. 从“游戏配置 → 翻译引擎与自定义 API”选择 MyMemory，点击测试并启用，确认联网前后状态明确、计数和错误能显示。
3. 使用自定义 HTTPS 端点、无密钥及有密钥端点各测试一次，验证换地址后不串用缓存。
4. 导入含敏感文字的游戏截图时，确认扫描强制本机处理；不要使用任何真实敏感截图进行在线测试。
5. 竖屏剧情与横屏菜单分别截图对照；OCR 术语命中、游戏配置保存、画面旋转中字幕切换。
6. 选择《勇者斗恶龙》游戏预设，测试「ホイミ」「スライム」「ぼうけんのしょ」和原创 RPG 台词的中文及自定义词覆盖。
7. 运行 30 分钟持续游戏、切换网络连接，观察 API 超时、PiP 字幕刷新、耗电及 app 前后台恢复情况。

**结论：源码改动与静态审核已完成；新版本的构建可用性、外部联网实测及真机可用性待验收。**
