# GameLingoAI 3.8.2 (Build 20) — 安全防递归、精细 OCR 和 PiP 性能

开发分支：`feature/universal-translation-3.8-beta`（原分支直接修改，无新分支）。更新：2026-10-24。

> 本版提交的是源码和 Codemagic 构建配置；**没有在真实 iPhone 运行或验证 Build 20 的 Xcode 完整构建**。所有性能目标须真机对照测试，不能保证固定延迟或小字识别率。

## 用户故障与技术处置

### P0 — PiP 自捕获、无限递归

iOS 27 的 ScreenCaptureKit 系统选择器在选择整个显示屏后，不能假设返回的采集帧排除了系统 PiP。源码原先将采集帧直接作为 PiP 新视频帧背景；PiP 又可能被下一次采集包含，从而形成无限套画面和重复文字识别。

**安全优先、默认禁止反馈循环**：
- 系统 PiP 真正激活时，如果没有经过验证的采集源排除保证，禁止向 PiP 回送任何完整采集游戏画面；
- 输出保持 **360×640 竖版画布**，但转为「实时译文 · 防递归安全显示」纯译文布局（最多显示最近 5 组），不是降低到低可读性的横版小字幕；
- 原文字与目标语言文本仍通过现有屏幕采集→Vision→Translation 更新；对已经知道是自身 PiP 所显示的**完全一致文本**增加第二层精确过滤，避免这些文字再次提交翻译。此过滤是辅助，不是系统窗口排除保证；
- 主界面提示降级状态，诊断事件 `pip_safety` 记录状态，不记录画面或文字；
- App 内可以仍保留竖版完整游戏画面的设置选项，但**系统未证明安全排除 PiP 时，活动 PiP 中不会持续展示镜像游戏画面**；目前功能为 fail-closed，不借助检测浮窗位置、蒙版猜测或使用私有 API 来冒险。

### P0 — PiP 渲染负载与诊断

减少实际 PiP 运行时全分辨率捕获帧 → CoreImage → CGImage → CoreGraphics → PiP 视频像素缓冲等重复图像转换：安全模式直接绘制文本文字，不进行完整背景图像回灌。保留原有最新帧优先队列、CVPixelBufferPool 重用、CoreText 缓存；去掉启动回调中的重复绘制。

新增 `pip_sample`，最多约每十秒一个聚合事件，记录 `pip_render_ms`、`pip_render_p50`、`pip_render_p95`、`pip_frames`、`pip_backpressure`、`pip_safe_mode`。值只用于比较，无游戏内容。既有 P50/P95 目标须根据实际 CPU/GPU 设备数据调优。

### P1 — 小字识别与位置补全

- 实时 Vision Fast 最低相对文字高度由 `0.012` 调整为 `0.009`，Accurate 精确回退使用 `0.005`；
- 独立串行的整屏菜单精细识别从 `0.006` 降至 `0.004`，允许在大对白出现的场景下少量运行，而不再被主对白完全禁止；有对白时自动扫描间隔不少于 6 秒，无对白时至少 3.5 秒；
- 保留底部 21% 区域 `0.003` 高精度 OCR，新增 **按行归一化位置结果**。`GameOCRSpatialMerge` 在主结果与底部补充结果之间去重且保存对应坐标。主文字与坐标不一致时不把中文胡乱贴在其它游戏文字上。
- 所有精细 OCR 都在辅助 utility 队列串行执行，不把同步 Accurate 运算移入实时采集回调。
- 已存在的系统完整菜单扫描、原位菜单、截图翻译仍可用。

### P2 — 回归与版本

- 新增 `tests/small_ocr_spatial_smoke.swift`：检测重复文字、小字位置、坐标失配降级及自身 PiP 精确回声过滤；
- `tools/build_xcodeproj.py` 将 `GameOCRSpatialMerge.swift` 纳入 Direct 目标；
- `tools/verify_universal_ocr.py` 增加防递归、坐标与诊断静态保护；
- `codemagic.yaml` 完整工作流包含静态检查、Swift 回归测试、Paddle 模型获取和未签名 iPhone 包编译；
- App 版本 **3.8.2 Build 20**；Codemagic 工作流 `ios-universal-ocr-unsigned`；
- 构建**成功后**预期产物为 `GameLingoAI-Universal-v3.8.2-b20-stable-unsigned.ipa`。

## 真机验收必须通过

1. **防递归**：选择完整屏幕、启动 PiP，并保持 20 分钟以上。PiP 应显示静态竖版文本安全模式，不再在自身画面内无限套画面；`pip_safe_mode=1`，不应出现持续再识别已显示译文造成的无限循环。
2. **性能**：同一 iPhone、同一游戏、同一语言和同一区域，比较 3.8.1 和 3.8.2 的 OCR P50/P95、PiP render P50/P95、背压增量、掉帧率、耗电和发热；注意 `ocr_sample` 仅是限频采样。
3. **小字**：使用经过人工标注的任务说明、菜单、底部 HUD、地图文字测试集，记录漏识别、误识别及原位坐标准确度，不能只看 Recognition 数量。某些极小字体低于屏幕原始像素分辨率，放大不保证恢复。
4. **状态管理**：PiP 多次开启/关闭、前后台转换、转屏、切换目标语言/游戏后，不能保留旧画面或将旧位置译文贴到新场景。
5. **iOS 授权**：保留系统 SCContentSharingPicker 授权；不使用任意窗口猜测/私有排除接口；若用户需要真正逐帧“PiP 中的游戏画面”，必须在实际系统采集方案能够证明排除 PiP 的前提下另行开放。

**不包含**：苹果快捷指令、新分支、新收费翻译服务、无授权采集或强行修改其他游戏里的原生文字。
