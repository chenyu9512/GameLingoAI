# GameLingo Universal OCR 3.7.1（Build 16）— 冷启动与满窗 PiP

更新：2026-10-24。分支：`feature/universal-ocr-ui-language`。对应 Codemagic 工作流：`ios-universal-ocr-unsigned`。

> **源码已更新，不代表 Codemagic 已成功生成 IPA 或已完成 iPhone 真机验收。** 本分支沿用原 Universal OCR 的 Vision + PaddleOCR 混合方案；`main` 3.5.3 与旧 ML Kit 实验分支不在本次修改范围内。

## 包含的改进

### 1. 冷启动准备
- 首页进入时，在低优先级队列上用不包含用户内容的 64×64 测试画面进行 Vision Fast 首次请求。
- Vision 的多语言支持列表复用既有缓存；自动 Fast OCR 候选收窄至常见的日/英/韩/简中四种，其他语言可由游戏配置显式指定。
- 检查当前游戏语言对的 Apple 离线翻译语言包是否已安装；只有已安装的语言对才尝试使用固定测试短句预热，不触发语言包下载或网络翻译。
- 在切换当前游戏、翻译服务或返回前台时刷新预热状态。若语言包未安装，仍须通过系统下载入口安装。
- 在本机 JSONL 中仅记录耗时及状态类别（`startup_vision`、`startup_translation`、`startup_ready`、`first_ocr`、`first_translation`），不保存原始文字或截图。

### 2. OCR 多次 Accurate 复检限频
- Vision Fast 的低置信度结果仍可使用 Accurate 兜底，但相同指纹的画面最多每 2 秒重新执行一次，以减少同一静态画面的重复复检。
- 保留最新帧队列和原有稳定性确认逻辑，诊断中增加 `accurate_suppressed` 统计。
- PaddleOCR 仍为按需增强模型，不强行与 Vision 首次预热抢占内存。真实效果应比较识别准确率与 OCR P50/P95，不能仅看重扫次数。

### 3. PiP 满窗、成对分页与菜单模式
- 新增 `满窗双语阅读`、`满窗中文阅读`、`原位菜单阅读` 三种布局，历史布局可继续使用。
- 使用整块 PiP 视频画布；新双语布局在较宽窗口中左右并排、窄窗口中上下排列。
- 原文与中文按“同一翻译对”分页，避免旧实现分别按字符数拆页导致某些页面错位；长文本保留每个 Unicode 字符，必须分页时显示下一页。
- 对窗口尺寸变化使用 `didTransitionToRenderSize` 重新分组，并更新 CoreVideo 像素缓冲池。
- 菜单模式使用 OCR 坐标辅助行布局，但属于小窗内的近似还原，不是修改游戏中文字，更不能任意指定系统 PiP 的屏幕 X/Y 位置。
- 新安装默认静态整页阅读；旧版使用标准滚动字幕的用户进行一次性升级迁移，可在偏好里重新启用自动翻页。

### 4. 一键启动与 PiP 准备
- 首页新增“**一键开始游戏翻译**”，默认勾选“开始时自动准备悬浮字幕”。
- 用户点击后尝试开启 PiP；只有收到实际 PiP 成功回调才接着呈现系统屏幕捕获选择器。
- 若 PiP 被系统拒绝，允许用户选择“**不使用 PiP，继续授权屏幕采集**”。
- 截图导入/截图翻译保留原有 App 内入口。**没有**增加 App Intents、快捷指令、桌面长按快捷操作或背面敲击触发。
- 小窗位置和可用的窗口尺寸始终受 iOS 管理，不能承诺可编程固定悬浮坐标或绕过系统捕获授权。

## 验证与观察

新增 `tests/pip_reading_smoke.swift`，由 Codemagic 编译并运行，核对原文/译文连续性、换行对应关系、分页容量与 Unicode 字符不丢失。静态项目检查扩展到新模块、版本号、诊断和 UI 状态机，并让 CI 对新增的 Swift 文件执行语法解析。

需要真机测试：
1. 首次安装后连续两次冷启动：记录 `cold_vision_ms`、`cold_translation_ms`、`first_ocr_ms`、`first_translation_ms`；
2. 对比 v3.7.0 与 3.7.1 同一款游戏、同一区域的 OCR P50/P95、准确率、热状态，以及每分钟 Accurate 次数；
3. 首次授权、PiP 成功、PiP 不可用、用户拒绝屏幕选择器以及后台切换场景；
4. 小窗在不同窗口大小和横竖屏下文字是否完整、是否适度分页，尤其是 100 字以上对白及 15 项菜单；
5. 双语阅读是否保持原文和译文配对、暂停翻页时是否保持静态，以及与动态字幕模式之间切换是否正确；
6. 核对未签名 IPA 文件名与 App 内版本。

**预期构建产物**（成功构建后才会产生）：`GameLingoAI-UniversalOCR-v3.7.1-b16-unsigned.ipa`。需要 SideStore 等进行签名安装，未签名 IPA 不能直接点开安装。
