# GameLingoAI 3.8.1 (Build 19)：竖版 PiP 游戏画面原位翻译

开发日期：2026-10-24。分支：`feature/universal-translation-3.8-beta`，**没有新建分支**；`main`、3.7.x 和 ML Kit 实验分支均未改变。

## 已提交内容

1. **竖版 PiP 视频画布**：新增 `portraitScene`（完整画面）和 `portraitFocus`（围绕文字聚焦）布局，渲染帧固定为 360 × 640，旧满窗双语和纯译文布局保留。
2. **真实授权屏幕画面**：`DirectGameCapture` 从现有 SCStream 帧中，独立按约 2 FPS 将最新 `CVPixelBuffer` 传给 PiP；回调切主线程，不进入积压任务队列。后台 OCR 和翻译任务按原节奏处理。
3. **高效画面合成**：`GamePiPFrameRenderer` 通过 Core Image 对已校正方向的游戏帧按视口裁切、降采样，生成小尺寸 `CGImage`，再画入 PiP 的 `CVPixelBuffer`。只保留最新可处理帧；不写入图片文件。
4. **原位文本层**：`GamePiPSceneLayout` 使用 Vision 的归一化左下坐标系转换文字框到竖版画布。实时 OCR 检测框保留到完成翻译后，仅当译文行数匹配才逐条覆盖；相同内容的新位置可直接复用缓存。整屏菜单继续使用原有已翻译位置块。
5. **系统兼容与恢复**：PiP 未许可或不支持时保留纯字幕回退模式；屏幕采集停止会清除上次的游戏画面；切换配置会清掉上一游戏坐标。
6. **App 交互**：首页字幕面板直接提供两种竖版模式与两种备用字幕模式。新安装默认竖版完整画面；从原默认满窗双语升级的旧用户执行一次性竖版模式迁移。
7. **构建与测试**：iOS 项目两种目标均收录 `GamePiPSceneLayout.swift`；新增 `tests/pip_scene_smoke.swift`，覆盖横屏游戏聚焦比例、竖屏显示和 Vision 框坐标。Codemagic 工作流升级为 **v3.8.1 Build 19**。

## 性能及限制

- 竖屏宽高是生成的视频输出比例，不是 iOS PiP 浮窗大小的公开可控接口；实际浮窗形态和可用性由系统决定。
- 2 FPS 是游戏画面预览的节流上限，不等于 OCR 采样或游戏本体刷新率。高分辨率背景帧交给 Core Image 先降采样，避免每次为 PiP 创建原尺寸的完整位图。
- 初次 PiP 启动时没有授权画面，先使用竖版占位视频帧；完成用户屏幕采集授权之后才会出现真实游戏画面。
- OCR 的实时位置来自 Vision 已接受的文本框；Paddle 增强、自动换行或翻译行数变化不能保证每一块匹配。匹配失败时不胡乱贴文字，用户可用原有满窗字幕查看完整译文。
- 整屏菜单只展示新近 OCR 扫描的翻译框，避免把很久以前的历史扫描结果套在当前画面上。
- 某些系统的屏幕采集可能包含 PiP 窗口本身，形成递归镜像；如果遇到此情况切换为纯字幕模式。本版尚未具备系统层排除 PiP 窗口的稳定保证。
- 当前屏幕仍可能因 OCR 延迟显示稍旧的文字覆盖；这是“画面采样”和“翻译结果”非完全同步的固有现象，不能承诺零延迟/像素级无痕替换。
- 长译文超过原文字框时自动扩展半透明背景，但依然可能遮挡游戏界面。不能保证所有文本在 PiP 小尺寸下完整显示。
- PiP 视频在内存中合成，不新增图片保存流程，不改变用户已选择的在线翻译提供商权限，也不绕过系统采集许可。

## 编译及设备验收

分支 `feature/universal-translation-3.8-beta`，Codemagic 工作流 `ios-universal-ocr-unsigned`，App 版本 **3.8.1 Build 19**。构建成功后预期 IPA：

`GameLingoAI-Universal-v3.8.1-b19-portrait-unsigned.ipa`

测试：
- 首次冷启动，系统 PiP 尚未显示游戏时应有竖版占位画面；完成采集授权后出现游戏视频
- 竖屏/横屏/游戏锁定横屏及用户自定义旋转：检查中文文字是否覆盖到对应的游戏位置
- 竖版完整画面 ↔ 竖版聚焦画面 ↔ 满窗字幕无延迟切换；横屏等比缩放，不拉伸人物
- 长剧情段落、底部静态菜单与多行译文，核对位置、遮挡情况和错误文字对应
- 10～15 分钟的画面预览、OCR 翻译，观察 Core Image 内存、CPU/GPU、发热、PiP 卡顿
- 从游戏切换到别的 App、结束屏幕采集、切换配置及停止 PiP，确认旧截图不长期留在窗口
- 检查屏幕采集是否递归捕获了 PiP；如果出现，保留纯字幕模式做降级
